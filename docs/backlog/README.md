# Backlog

Tasks are tracked as Markdown files named `<index>_<task-slug>.md`, moved between state directories
as work progresses:

- `open/` - open tasks awaiting work
- `pending-review/` - completed tasks awaiting review
- `done/` - completed and reviewed tasks

Move a task file from one directory to the next as its status changes. For short-lived, in-flight
work use the checklist in `../todo.md` instead of a full task file.
